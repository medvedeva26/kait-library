Четыре группы без серверной проверки значений: 5, 6, 11, 18. Это не означает, что остальные полностью безопасны: у большинства проверка частичная.

Маршруты без собственных полей тоже учтены: catalog, logout, profile, librarian, reservations, admin_users используют page и/или сессию; API loans.my и readers — action и сессию. Дополнительных параметров формы у них нет. user_id отзыва и брони берётся из Auth, отдельного поля пользователя для него нет.

Authorization в коде не используется. Для API существенны Cookie и Content-Type, для загрузки — multipart-данные и имя файла. Вебхуков, внешнего API и чтения localStorage нет. .env и SQL-скрипты заполняет разработчик при установке; это настройки окружения, а не пользовательские точки ввода веб-приложения.

В формах и изменяющих API-действиях не найден CSRF-токен. HTML-проверку можно обойти прямым запросом, поэтому ограничения нужны и на сервере. Исправления относятся к следующим модулям; сейчас код сохранён в исходном виде.
