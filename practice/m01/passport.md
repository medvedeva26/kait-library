## 4. Зависимости

Сторонних пакетов нет. Перечисляю только используемые компоненты.

| Компонент | Версия | Зачем нужен |
|---|---|---|
| PHP | 8.4.6 при запуске | Выполняет серверный код |
| PDO, pdo_mysql | В составе PHP | Подключение к MySQL и SQL-запросы |
| mbstring | В составе PHP | Длина пароля и первая буква названия книги |
| session | В составе PHP | Хранение входа пользователя |
| JSON | В составе PHP | Обмен данными между JavaScript и API |
| MySQL | 8.4 при запуске | Хранение данных библиотеки |
| Fetch API | Встроен в браузер | Запросы поиска, отзывов и других действий |

README указывает PHP 8 и MySQL 8 без точных версий. Оценивать устаревание сторонних пакетов здесь не требуется: их нет. Но в собственном коде есть спорные решения, например MD5 для паролей в src/Auth.php.

## 6. Запуск

Проверка выполнена на Windows: PHP 8.4.6, MySQL в Docker, адрес http://localhost:8083/. Настройки БД лежат в локальном .env и не отправляются в Git.

Рабочие команды из корня проекта:

```text
Copy-Item .env.example .env
php -v
php -m
php -d extension=pdo_mysql -S 127.0.0.1:8083 -t public
```

Создана база kait_library. Сначала импортирован database/schema.sql, затем database/seed.sql. В моём окружении импорт выполнен контейнером при первом запуске через каталог /docker-entrypoint-initdb.d. Подключение: 127.0.0.1:3307, пользователь БД medvedeva. Пароль хранится только в .env.

В исходном README не было шагов настройки .env и импорта seed.sql. Без учебных данных каталог пустой. В установленном PHP не был включён драйвер pdo_mysql: подключила его параметром запуска. Эти сведения добавлены в README.

После запуска в каталоге 10 книг. Зарегистрировала тестовую учётную запись «Медведева Александра Андреевна», группа ИСПО332. Поиск SQL вернул две книги, страница «Изучаем SQL» открылась. Код приложения для запуска менять не пришлось.

## 7. Вывод о проекте

Структура проекта небольшая и понятная: страницы, API, классы и шаблоны разнесены по папкам. Приложение удалось запустить с MySQL и учебными данными. Инструкцию пришлось дополнить настройкой подключения и загрузкой данных. Начать подробное ревью стоит с обработчиков запросов и LoanService, потому что они менялись чаще всего. В поиске строки запроса собираются напрямую из параметров, а для отзывов нет серверной проверки длины и оценки. Это конкретные места для следующих модулей. Паспорт и статистика помогут сопоставить код с диаграммами потоков данных.
