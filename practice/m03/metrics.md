## 4. Почему появился большой diff

VS Code вернул табуляцию в ReportService.php. После форматирования в NetBeans Git показал 77 добавленных и 80 удалённых строк. Изменились отступы и положение открывающих скобок. В таком сравнении трудно найти одну строку с настоящим исправлением.

## 5. Находки

В LoanService.php проверка лимита использует строгое сравнение «больше». При числе книг, равном лимиту, выдача ещё разрешена. В ReportService.php штраф считается по 15 рублей в день, а в правилах библиотеки указано 10. Обе находки оставлены для модуля исправления ошибок.
