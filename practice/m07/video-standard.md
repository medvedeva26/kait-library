# Средства просмотра видео и стандарт видео-багрепорта

Медведева Александра Андреевна, ИСПО332.

## Задача выбора

Выбираю проигрыватель для разбора записи ошибки «Библиотеки КАИТ». Сравниваю VLC, mpv.net, Медиаплеер Windows и Chrome. Для записи использую OBS, затем сравню MKV, MP4, WebM и MP4 720p.

## Критерии и веса

| № | Критерий | Вес | Проверка | Почему такой вес |
|---|---|---|---|---|
| 1 | MP4, MKV и WebM | 0.15 | Открытие трёх файлов | Видео может прийти в разных форматах |
| 2 | Покадровый просмотр | 0.20 | Кадр вперёд и назад | Нужно найти момент появления ошибки |
| 3 | Замедление | 0.15 | Скорость 0,25× | Нужно рассмотреть быстрые действия |
| 4 | Снимок кадра | 0.15 | Сохранение изображения | Кадр нужен для Issue |
| 5 | Повтор фрагмента | 0.10 | Метки A и B | Удобно повторять участок с ошибкой |
| 6 | Увеличение | 0.05 | Увеличение части кадра | Нужно прочитать мелкий текст |
| 7 | CPU и память | 0.10 | MP4 1080p, три замера по 30 с | Просмотр не должен сильно нагружать компьютер |
| 8 | Лицензия и реклама | 0.10 | Условия лицензии и проверка интерфейса | Не нужны подписка и реклама |

Сумма весов — 1,00. Критерии и шкала записаны до испытаний.

## Шкала оценок

| № | 5 | 3 | 1 |
|---|---|---|---|
| 1 | Открывает все три | Открывает MP4 и ещё один формат | Открывает только MP4 или не открывает MP4 |
| 2 | Есть шаг вперёд и назад | Только вперёд | Покадрового шага нет |
| 3 | Есть 0,25× | Есть замедление, но минимум выше 0,25× | Замедления нет |
| 4 | Сохраняет PNG без интерфейса | Сохраняет кадр только с потерями или через буфер | Своего сохранения кадра нет |
| 5 | Есть повтор A–B | Повторяется только весь ролик | Повтора нет |
| 6 | Есть увеличение части кадра | Только полный экран или размер окна | Нельзя увеличить изображение |
| 7 | CPU до 5%, память до 500 МБ | CPU до 10%, память до 1000 МБ | Хотя бы одно значение выше границы оценки 3 |
| 8 | Бесплатный открытый плеер без рекламы | Бесплатный закрытый плеер без рекламы | Есть реклама или нужные функции платные |

Использую оценки 5, 3 и 1. Если результат находится на границе, действует включённая граница из таблицы.

Для измерения нагрузки использую один MP4 1080p. Для оценки 5 должны выполняться обе границы, иначе проверяю условия оценки 3. Телеметрию проверю по сведениям разработчиков отдельно: отсутствие рекламы не означает отсутствие телеметрии.

План ролика: воспроизвести находку М03 — выдачу книги при уже достигнутом лимите. Запись 60–90 секунд, захват только окна проекта и курсора, микрофон выключен. Черновики храню вне репозитория.

В конце поменяю местами веса двух главных критериев и проверю, изменился ли победитель.
